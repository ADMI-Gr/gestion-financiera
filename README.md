# Gestión Financiera

App web personal para llevar el control de gastos: cuentas, tarjetas, movimientos, compromisos (pagos mensuales y deudas), presupuestos y reportes.

- 100 % estática (HTML, CSS y JavaScript), sin servidor ni dependencias externas: funciona sin internet.
- Los datos se guardan en el navegador (`localStorage`) de quien la usa; nada se envía a ningún servidor.
- Respaldo con los botones **Exportar** / **Importar** (archivo `.json`).

## Uso

Publicada con GitHub Pages: https://admi-gr.github.io/gestion-financiera/

Para usarla localmente basta con abrir `index.html` o servir la carpeta con cualquier servidor estático.
